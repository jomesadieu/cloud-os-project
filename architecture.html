How a visitor sees the site

  1. A visitor requests the website in a browser using its HTTPS address.
  2. Cloudflare Pages receives the request and serves the deployed files.
  3. The browser displays the HTML and CSS and runs the JavaScript.

GitHub stores the source files. When changes are pushed to the connected production branch, Cloudflare can deploy the updated site.

Who manages what?

Cloudflare manages

  • The hosting infrastructure and delivery of deployed files.
  • The platform used to build and deploy the connected site.
  • HTTPS for the provided website address.

The developer manages

  • The website's content, code, and accessibility.
  • Repository access and account security.
  • Deployment settings, testing, and published changes.

Cloud hosting and a local server

With a local web server, the owner typically installs server software, maintains the operating system, applies updates, and manages network availability. A managed cloud platform handles much of the underlying infrastructure, while the developer remains responsible for the site and its configuration.

HTTPS protects data while it travels between the browser and the service. It does not decide who is authorized to view a page, and it does not hide secrets placed in publicly delivered JavaScript.
